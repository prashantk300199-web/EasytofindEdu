API Documentation

Base URL: http://localhost:5000/api/v1/career-guidance

Public Endpoints

1. GET /questions
Rate Limit: 100 requests per 15 minutes
Description: Fetch all active questionnaire questions

Response:
{
  "success": true,
  "statusCode": 200,
  "data": [
    {
      "_id": "...",
      "questionNumber": 1,
      "questionText": "What is your highest qualification?",
      "questionType": "dropdown",
      "category": "qualification",
      "options": [
        { "label": "Class 12th", "value": "class_12th" }
      ],
      "isRequired": true,
      "tags": ["education", "qualification"]
    }
  ],
  "message": "Questions retrieved successfully"
}

2. GET /featured-courses
Rate Limit: 100 requests per 15 minutes
Description: Get featured courses for homepage

Response:
{
  "success": true,
  "statusCode": 200,
  "data": [
    {
      "_id": "...",
      "title": "B.Tech (Computer Science)",
      "slug": "b-tech-computer-science",
      "nodeType": "course",
      "description": "4-year undergraduate degree",
      "cost": { "average": 800000, "currency": "INR" },
      "duration": { "value": 4, "unit": "years" },
      "isFeatured": true
    }
  ],
  "message": "Featured courses retrieved successfully"
}

3. GET /search?qualification=class_12th&stream=pcm
Rate Limit: 50 requests per 5 minutes
Parameters:
  - query: Search text (optional)
  - qualification: class_8th, class_10th, class_12th, etc (optional)
  - stream: pcm, pcb, commerce, etc (optional)
  - nodeType: course, entrance_exam, etc (optional)
  - minCost, maxCost: Cost range in ₹ (optional)
  - minSuccessRate, maxSuccessRate: 0-100 (optional)
  - page: Page number (default: 1)
  - limit: Items per page (default: 20, max: 100)

Response:
{
  "success": true,
  "statusCode": 200,
  "data": {
    "courses": [...],
    "pagination": {
      "page": 1,
      "limit": 20,
      "total": 150,
      "totalPages": 8
    }
  }
}

4. POST /submit-answers
Rate Limit: 10 per hour per user/IP
Body:
{
  "answers": {
    "qualification": "class_12th",
    "stream": "pcm",
    "relocationWilling": "yes",
    "preferredCities": ["delhi", "bangalore"],
    "financialCapacity": "middle",
    "timeframe": "medium_term",
    "careerGoal": "Software Engineer",
    "expertiseSubject": "Mathematics"
  }
}

Response:
{
  "success": true,
  "statusCode": 200,
  "data": { "message": "Answers received" },
  "message": "Answers submitted successfully"
}

Response Format

All responses follow this format:

{
  "success": true/false,
  "statusCode": 200/400/404/500,
  "data": { /* Response data */ },
  "message": "Human-readable message"
}

Common Status Codes:
- 200: Successful
- 400: Bad request (invalid parameters)
- 404: Resource not found
- 429: Rate limited
- 500: Server error

Rate Limiting

Public Endpoints:
- General: 100 requests per 15 minutes per IP
- Search: 50 requests per 5 minutes per IP
- Question Submission: 10 per hour per user/IP

Headers in Response:
- RateLimit-Limit: Maximum requests allowed
- RateLimit-Remaining: Requests remaining
- RateLimit-Reset: Unix timestamp when limit resets
